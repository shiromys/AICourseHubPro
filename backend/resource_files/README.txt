Template files for the free resource library go in this folder (backend service, NOT the website folder),
so a template can only be downloaded after the visitor has entered an email address.

Rules for file names: lower-case letters, digits, dots, dashes; ending .docx .xlsx .pptx .pdf .csv .md or .txt.
Example: grant-proposal-first-draft.docx
The same name must be written in the page's "template.file" field in frontend/src/content/resourceContent.js.
